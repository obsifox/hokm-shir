- حالت کلاسیک ۴ نفره (تیم، حاکم، کوت، امتیاز تا ۷ ست)

- بازی با دوستان روی هات‌اسپات (بدون اینترنت)
- دست کارت گرد + سوایپ + مرتب‌سازی + انیمیشن‌ها و ۲۰ افکت صوتی
